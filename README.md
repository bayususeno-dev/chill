# CHILL

## Description

A movie streaming platform website designed to provide an engaging entertainment experience. Users can explore movies and series through a modern interface, with login and registration pages.

## Features

- Homepage
- Login page
- Registration page
- Movie and series collections
- Continue Watching section
- Trending movies and series
- Movie cards with hover interactions
- Reusable UI components
- Responsive layout for desktop, tablet, and mobile
- Form interactions and basic input validation
- Client-side navigation using React Router

## Technologies

- React JS
- JavaScript
- Vite
- CSS
- React Router DOM

## Project Structure

Main project folders:

- `public/assets/` → Images, icons, and other static assets
- `src/components/` → Reusable UI components
- `src/pages/` → Homepage, login, and registration pages
- `src/data/` → Local movie and series data
- `src/App.jsx` → Main application component and route configuration
- `src/main.jsx` → Application entry point
- `src/index.css` → Global styles
